# Разбор проекта «Оқу» — для Мұхана

Это не документ для сдачи, а шпаргалка для тебя: что сделано, как это работает и почему именно так. Всё простыми словами. Прочитай целиком один раз до предзащиты — на большинство вопросов преподавателя ответ здесь.

---

## 1. Проект за одну минуту

«Оқу» — электронная библиотека в браузере. Сервер на **Python + FastAPI**, данные в **SQLite**, интерфейс — одна HTML-страница на **чистом JavaScript**. Все функции доступны через **REST API** (адреса `/api/...`), документация API строится сама на `/docs`.

Обязательное по варианту 11 и где это:

| Требование | Где посмотреть | Как показать на защите |
|---|---|---|
| FastAPI | `app/web.py` | открыть `/docs` |
| JWT | `app/security.py`, вход в `web.py` (`/api/auth/login`) | в `/docs` выполнить login → Authorize → вызвать `/api/me` |
| Постраничный вывод | `service._paginate`, каталог | внизу каталога кнопки страниц; в API параметры `page`, `page_size` |
| Журнал действий (усложнение) | таблица `action_log`, `web.audit()` | Модерация → Журнал действий, фильтр, CSV |

## 2. Как устроены файлы (что открыть, если спросят «покажи код»)

```
app/service.py    ← ГЛАВНЫЙ файл: все правила (права, книги, поиск, баны, журнал)
app/web.py        ← принимает HTTP-запросы и вызывает service.py
app/db.py         ← схема базы (16 таблиц) и подключение
app/security.py   ← хэш паролей и JWT
app/profanity.py  ← цензура
app/schemas.py    ← какие поля принимает API (Pydantic)
static/js/core.js ← ядро сайта: запросы к API, переводы, переходы между страницами
static/js/views.js← страницы сайта
static/js/admin.js← модерация и журнал
tests/ ← 152 теста (test_service.py, test_game.py)
```

**Главная мысль (её спросят 100%):** `service.py` не знает, что такое сайт. Он принимает данные и возвращает результат. Поэтому:
1. его можно тестировать без запуска сервера (тесты идут меньше секунды);
2. его можно подключить к настольной или мобильной версии — это ответ на «что нужно для второй платформы».

## 3. Понятия простыми словами

| Термин | Объяснение «на пальцах» |
|---|---|
| **REST API** | Набор адресов, по которым программы просят данные. `GET /api/books` — «дай книги», `POST /api/books` — «добавь книгу». Ответ — JSON (текст вида `{"title": "..."}`) |
| **OpenAPI / Swagger** | Стандартное описание API. FastAPI сам строит по коду страницу `/docs`, где все адреса можно вызвать кнопкой |
| **JWT** | «Пропуск» после входа. Сервер подписывает его секретным ключом; подделать нельзя — подпись не сойдётся. В пропуске записаны id пользователя и срок действия |
| **Access и refresh токены** | Access — короткий пропуск (30 мин) для каждого запроса. Refresh — длинный (7 дней), им получают новый access, не вводя пароль снова |
| **Хэш пароля** | Одностороннее «перемалывание»: из пароля легко получить хэш, из хэша пароль — нельзя. В базе лежит только хэш |
| **Соль** | Случайная добавка к паролю перед хэшированием. Из-за неё у двух людей с паролем «12345678» разные хэши |
| **PBKDF2, 600 000 итераций** | Хэш считается 600 тысяч раз подряд. Для одного входа это 0,3 секунды, а для перебора миллионов паролей — годы. Число рекомендовано OWASP |
| **Брутфорс** | Подбор пароля перебором. У нас: 5 ошибок → блок на 10 секунд + не больше 10 попыток в минуту с одного IP |
| **SQL-инъекция** | Когда в поле ввода пишут кусок SQL-кода. Защита: запросы с `?` — данные передаются отдельно и не могут стать командой |
| **XSS** | Когда в комментарий вставляют `<script>`. Защита: мы всё выводим через функцию `esc()`, которая превращает `<` в безопасный символ, + заголовок CSP запрещает чужие скрипты |
| **CSRF** | Атака, когда чужой сайт заставляет браузер отправить запрос с твоими cookie. У нас токен в заголовке, а не в cookie, поэтому атака невозможна |
| **Принцип наименьших привилегий** | Каждой роли — только нужные права. Модератор банит, но не трогает книги; автор меняет только свои книги |
| **Пагинация** | Выдача списка по страницам: не 10 000 книг сразу, а по 20 |
| **SPA (одностраничное приложение)** | Сервер отдаёт одну страницу, а разделы меняются по адресу после `#` (`#/catalog`, `#/book/5`) без перезагрузки |
| **i18n** | Переводы. Все надписи лежат в `static/i18n/ru.json`, `kk.json`, `en.json` по ключам |
| **WAL** | Режим SQLite, при котором чтение не ждёт окончания записи |
| **Миграции** | Если база создана старой версией, недостающие столбцы добавляются сами при запуске |
| **Покрытие тестами** | Какой процент строк кода выполнился во время тестов. У нас 89,3% |

## 4. Решения и почему они такие (вопрос «почему?»)

- **FastAPI, а не Flask** — требование варианта; плюс сам делает документацию OpenAPI и проверяет входные данные.
- **SQLite, а не PostgreSQL** — один файл, не нужен сервер базы, запуск одной командой на любом ноутбуке. Минус: одновременно пишет один процесс. Для учёбы хватает; переход на PostgreSQL меняет только `db.py`.
- **Чистый JavaScript, а не React** — нечего собирать и устанавливать; сайт работает сразу после копирования папки.
- **PBKDF2 из стандартной библиотеки, а не bcrypt** — нет внешних зависимостей с нативным кодом (на Python 3.15 они плохо ставятся, а для мобильной сборки это важно).
- **Журнал в базе И в файле** — база для модератора (фильтры, CSV), файл `instance/logs/oqu.log` для администратора сервера (все запросы и ошибки).
- **Права в одном словаре `PERMISSIONS`** — легко проверить и показать; одно место вместо проверок по всему коду.
- **Мягкое удаление комментариев** (`is_deleted = 1`) — модератор может восстановить картину нарушения.
- **Платная книга становится бесплатной сама** — дата `paid_until`; при каждом запросе проверяется, не прошла ли она. Не нужны фоновые задачи.
- **Забаненный подаёт заявку по логину и паролю** — токен ему не выдаётся, иначе бан был бы бессмысленным.

## 5. Что было найдено и исправлено (хорошо рассказать — это «честная разработка»)

1. Поиск по кириллице не работал: функция `LOWER` в SQLite знает только латиницу → заменили её функцией Python.
2. Сервер падал при параллельных запросах (поток SQLite) → `check_same_thread=False`.
3. Английская версия «съезжала» на телефоне → поиск перенесли во вторую строку; автоматическая проверка 72 вариантов.
4. Цензура не ловила настоящий мат и могла испортить «страхует» → новый модуль `profanity.py`, тесты в обе стороны.
5. Ошибка формы была непонятной (цена 999 999 999 999) → ошибки показываются у конкретного поля.
6. 240 000 итераций хэша — меньше рекомендации OWASP → стало 600 000.
7. На сервере без демо-данных нельзя было создать администратора → команда `python -m app.seed --create-owner`.

## 6. Вероятные вопросы преподавателя и ответы

**— Покажите, где бизнес-логика отделена от интерфейса.**
`app/service.py` — в нём нет ни одного импорта FastAPI. `web.py` только вызывает функции оттуда, например `service.add_book(...)`.

**— Как работает вход?**
`POST /api/auth/login` → `service.authenticate` берёт пользователя из базы, хэширует введённый пароль с его солью и сравнивает с сохранённым хэшем через `hmac.compare_digest`. Если 5 ошибок подряд — блок на 10 секунд. При успехе выдаём два JWT.

**— 10 секунд блокировки — не мало?**
Это специально для показа на защите, чтобы не ждать. Срок задаётся переменной окружения `OQU_LOCKOUT_SECONDS` — для настоящей работы ставим 900 (15 минут). Кроме того, есть второй барьер: не больше 10 попыток в минуту с одного IP, так что перебор всё равно идёт очень медленно. Сколько ждать, сервер сообщает сам (`retry_after`), и окно входа показывает обратный отсчёт.

**— Где хранится секретный ключ JWT?**
В переменной окружения `SECRET_KEY`. Если её нет (на ноутбуке), ключ создаётся случайно в `instance/secret.key`, а эта папка не попадает в Git.

**— Что будет, если токен украдут?**
Токен доступа живёт 30 минут. Риск снижен защитой от XSS (экранирование + CSP). Для большей защиты можно перейти на cookie `HttpOnly` — это указано в ограничениях.

**— Как сделана пагинация?**
Функция `_paginate`: считаем общее число (`COUNT(*)`), берём нужную страницу через `LIMIT ? OFFSET ?`, возвращаем `items, total, page, page_size, pages`. Размер страницы ограничен 100.

**— Что такое журнал действий и что в нём пишется?**
Таблица `action_log`: кто, что, подробности, IP, время в UTC. Пишется функцией `audit()` при входе, неудачном входе, регистрации, книгах, комментариях, банах, ролях, покупках и заявках. Модератор фильтрует и выгружает CSV. Старше 365 дней — удаляется.

**— Почему время в UTC?**
Чтобы не зависеть от часового пояса сервера. Браузер сам показывает его в местном времени.

**— Как устроены права?**
Словарь `PERMISSIONS`: роль → набор строк-прав (`book.add`, `user.ban`...). Перед действием вызывается `require_permission(роль, право)`. У владельца — все права.

**— Модератор может удалить книгу?**
Нет: у него нет права `book.delete`. Есть тест `test_moderator_cannot_touch_books`.

**— Как защищены от SQL-инъекции? Покажите.**
Любой `db.execute(...)` в `service.py` — с `?`. Единственное место, где в SQL подставляется имя столбца — сортировка, но имя берётся только из словаря `_SORT_SQL`. Тест `test_search_injection_in_sort_is_ignored` передаёт `title; DROP TABLE books` — таблица цела.

**— Как работает цензура?**
Текст переводится в «нормальную» форму (латинские x, y, o → русские), затем ищутся корни мата: одни — в любом месте слова, другие — только в начале слова или после приставки, чтобы не задеть «страхует» или «колебался». Найденное заменяется звёздочками, первая буква остаётся.

**— Сколько тестов и что они проверяют?**
130. Три вида случаев: обычный (регистрация работает), граничный (пароль 7 символов, страница за концом списка, оценка 0 и 6), ошибочный (неверный пароль, чужой комментарий, инъекция). Покрытие 89,3%.

**— Как считали покрытие?**
`run_coverage.py` — свой измеритель без пакета coverage: запоминает, какие строки выполнились во время pytest (`sys.settrace`), и делит на число исполняемых строк.

**— Почему 16 таблиц, а не 3?**
По заданию минимум 3. Нам понадобились связи «многие ко многим» (полки, оценки, закладки, покупки) и модерация (баны, заявки), поэтому таблиц больше.

**— Что нужно, чтобы запустить на телефоне?**
Сервер не меняется. Пишем клиент на Flet, который обращается к тому же API, и собираем `flet build apk`. Клиент хранит адрес сервера и токен; язык переключается в настройках приложения.

**— Что за правило трёх цветов?**
60–30–10: 60% — фон (бумага), 30% — текст (чернила), 10% — акцент (зелёный). Красный — только ошибки. Написано в начале `static/css/app.css`.

**— Вы использовали ИИ?**
Да, как ассистента: для черновиков кода и документов. Но всё проверяли тестами и вручную, часть ошибок ИИ (поток SQLite, ложные срабатывания цензуры, мало итераций хэша) нашли именно проверкой. Понимаем каждую часть — можем объяснить любой файл.

**— Пользовательское соглашение юридически корректно?**
Опирается на законы РК: договор присоединения (ст. 389 ГК РК), закон о персональных данных № 94-V, об авторском праве № 6, об информатизации № 418-V. Согласие — обязательная галочка при регистрации, дата и редакция сохраняются. Перед публикацией нужно вписать e-mail для обращений.

**— Как работает защита от накрутки в игре «Парақ»?**
Браузер считает страницы сам и раз в 20 секунд отправляет прогресс на сервер (`PUT /api/game/me`). Сервер ничему не верит на слово (`service.save_game`): проверяет, что на купленные улучшения хватило бы собранных страниц; что кликов не больше 20 в секунду; что страниц прибавилось не больше, чем могли дать улучшения и клики за прошедшее время (с запасом в 1,5 раза). Иначе — ошибка 400. Таблица улучшений одна на сервер и браузер (`GET /api/game/config`). Тесты — `tests/test_game.py`.

**— Почему картинки книг (`/media/...`) открываются без входа?**
Тег `<img>` не умеет отправлять JWT-заголовок. Поэтому картинки отдаются публично, но имена у них случайные (32 символа), угадать нельзя; путь проверяется регулярным выражением, чтобы нельзя было выйти из папки (`../`). Картинка проверяется по первым байтам (сигнатуре), а не по имени файла.

**— Как рисуются формулы?**
В тексте книги формула пишется на LaTeX: `$$ … $$` отдельной строкой или `\( … \)` внутри абзаца. Библиотека Temml (лежит у нас в `static/vendor`, без интернета) превращает её в MathML — математическую разметку, которую браузер рисует сам. Грузится только на страницах, где есть формулы.

**— Откуда тексты и картинки? Не нарушаете авторское право?**
Классика — общественное достояние (авторы умерли больше 70 лет назад): тексты взяты из Викитеки и Project Gutenberg, портреты авторов и рисунки Тенниела к «Алисе» — с Викисклада (лицензия Public domain, список — `app/demo/img/SOURCES.json`). У «Гарри Поттера» и Re:Zero только названия, авторы, годы и наши собственные аннотации; обложки рисует сам сайт, картинки издателей не используются.

## 7. Сценарий живого показа (3–4 минуты)

0. **Утром перед защитой:** `python -m app.seed --reset` — демо-база вернётся в исходное состояние (заявка `applicant01` снова будет ждать проверки, исчезнут тестовые комментарии).
1. `start.bat` → сайт открылся. Список языков (глобус вверху): English / Русский / Қазақша — всё переводится.
2. Каталог: ввести «Абай» в поиск, фильтр «Казахский», переключить вид на «Таблица». Сбросить фильтры → внизу кнопки страниц, перейти на страницу 2 → это **пагинация** (88 книг по 24 на странице — 4 страницы).
3. Шкаф: выбрать жанр, нажать на корешок → анимация.
4. Войти `reader01` (окно входа → «Демо-аккаунты»). Открыть «Анна Каренина» → «Продолжить» → читалка открылась на сохранённом месте.
5. Открыть почти любую книгу → в комментариях Едіге (спамер) мат уже заменён звёздочками; можно и самому написать грубое слово → звёздочки (**цензура**).
6. Открыть платную новинку «Основы Python» → замок и кнопка покупки. Войти `muhan` и открыть её в читалке → глава «Немного математики» с **формулами**; «Alice's Adventures in Wonderland» → **иллюстрации** Тенниела; «Қара сөздер» — обложка с фотографией Абая.
6½. Раздел «Парақ» → понажимать на книгу, купить «Закладку» → в «Статистике» внизу — рекорды игры (Мұхан там третий, на общих основаниях).
7. Выйти, войти `banned01` → окно бана «навсегда» с причиной, написать и отправить заявку (у `spammer01` заявка уже подана заранее).
8. Войти `moder01` → Модерация → Заявки на разбан → одобрить заявку `banned01`; вкладка «Студенты» → фото студбилета `applicant01` → одобрить; Журнал действий: видно все шаги выше с временем и IP → кнопка CSV (**усложнение**).
9. Открыть `/docs` → `POST /api/auth/login` → скопировать `access_token` → Authorize → `GET /api/me` (**JWT + OpenAPI**).
10. В терминале: `python -m pytest -q` → `152 passed`.
