https://claude.ai/artifact/5vfrmoKUH4QW95LREJtkTo

Сценарий: задание (бэкенд) → как выглядит бэкенд (/docs) → сверх задания сделан сайт → зачем → архитектура → JWT и страницы → журнал → роли → интерфейс → качество → итог.

**Кто говорит:** цветная полоса слева на слайде - зелёная = Мұхан, оранжевая = Хадизат.

Папка `исходники/` - код слайдов (deck.json, deck.css, slides/*.html), чтобы их можно было восстановить или переделать. Скриншоты в слайдах хранятся внутри артефакта.
