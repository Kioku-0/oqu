# Презентации

Слайды открываются в браузере по ссылкам (оттуда же скачиваются в PPTX или PDF):

| Версия | Ссылка | Речь (текст для чтения) |
|---|---|---|
| Казахский + русский (Хадизат - каз, Мұхан - рус) | https://claude.ai/artifact/RGcpoYPbDf4SpXgeLTyKeB | [Речь (каз-рус).md](Речь%20(каз-рус).md) |
| Всё на русском | https://claude.ai/artifact/3zeVdRoDZGzVDfmnvYjkDu | [Речь (рус).md](Речь%20(рус).md) |

**Как скачать PowerPoint или PDF:** открыть ссылку → кнопка скачивания в правом верхнем углу → PPTX или PDF. Положить файл сюда, в эту папку.

**Кто говорит:** цветная полоса слева на слайде - зелёная = Мұхан, оранжевая = Хадизат. В файлах речи это подписано после названия слайда.

Папка `исходники/` - код слайдов (deck.json, deck.css, slides/*.html), чтобы их можно было восстановить или переделать. Скриншоты в слайдах хранятся внутри артефакта.
