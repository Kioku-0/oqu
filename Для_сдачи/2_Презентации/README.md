# Презентации

## Основная: предзащита, 12 слайдов (PowerPoint)

| Файл | Текст на слайдах | Речь Хадизат | Речь Мұхана |
|---|---|---|---|
| `Оқу_предзащита_рус-каз.pptx` | казахский | казахский | русский |
| `Оқу_предзащита_рус-кыр.pptx` | кыргызский (название - «Окуу») | кыргызский | русский |
| `Оқу_предзащита_рус.pptx` | русский | русский | русский |

Слайды во всех трёх одинаковые по содержанию и оформлению, отличается только язык. Переводы текста слайдов - `исходники/slides_kk.py` и `исходники/slides_ky.py`. Стиль - «тетрадь в клетку и книжная полка»: скриншоты-полароиды, пометки ручкой, стикеры, полка с корешками внизу. **Кто говорит - видно по закладке-ленточке сверху справа** (на ней номер слайда): фиолетовая - Мұхан, жёлтая - Хадизат.

| № | Слайд | Кто |
|---|---|---|
| 1 | Обложка | Хадизат |
| 2 | Зачем: проблема, решение, сравнение с аналогами | Хадизат |
| 3 | Задание варианта 11: требование → как выполнено → где в коде | Мұхан |
| 4 | Бэкенд: Swagger и пример запроса с постраничным выводом | Мұхан |
| 5 | Архитектура и почему эти технологии, вторая платформа | Мұхан |
| 6 | База данных: 16 таблиц и ограничения | Мұхан |
| 7 | Вход по JWT и защита данных | Мұхан |
| 8 | Журнал действий (усложнение) | Хадизат |
| 9 | Семь ролей | Хадизат |
| 10 | Интерфейс | Хадизат |
| 11 | Тесты: граничные случаи | Мұхан |
| 12 | Итог, QR-код на сайт | Хадизат |

**Речь** - в заметках к слайдам (в PowerPoint: Вид → Заметки; при показе её видит только докладчик). У слайдов Мұхана после речи есть блок **«ЕСЛИ СПРОСЯТ»** - готовые ответы на вопросы преподавателя (что такое REST и OpenAPI, почему не Django, ограничения SQLite, где секретный ключ, почему блокировка 10 секунд, что такое покрытие и т.д.).

Пересобрать после правок: `python исходники/make_pptx.py` (нужно `pip install python-pptx qrcode`). Тексты слайдов - в `исходники/make_pptx.py`, речь - в `исходники/notes.py`.
