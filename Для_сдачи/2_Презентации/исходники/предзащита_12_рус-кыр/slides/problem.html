[Хадизат, кыргызча] Бул долбоор эмне үчүн керек? Университеттин МегаПро китепканасын телефондон колдонуу ыңгайсыз, жана ал кайсы бетте токтогонуңузду эстеп калбайт. Биздин студенттер казак, орус жана англис тилдериндеги китептерди окушат, ошондуктан интерфейс да эне тилинде болушу керек. Биз окшош сайттарды салыштырдык: ЛитРес, MangaLib, Kitap.kz. Алардын ар биринде окууга керектүү бир нерсе жетишпейт: биринде казак тили жок, бири акылуу, эч биринде ачык API жок. «Оқу» ушул кемчиликтердин баарын жабат: окууну токтогон жерден улантса болот, интерфейс төрт тилде, API ачык, студенттерге акысыз.
