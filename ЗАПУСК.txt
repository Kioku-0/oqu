КАК ЗАПУСТИТЬ ПРОЕКТ (Windows)
================================

САМЫЙ ПРОСТОЙ СПОСОБ:
  1. Распакуйте архив (правый клик по zip -> "Извлечь все").
  2. Откройте папку korkyt-library.
  3. Дважды щёлкните по файлу  start.bat
  4. Откроется чёрное окно и подождите ~1 минуту (первый раз
     устанавливаются нужные библиотеки). Потом сам откроется браузер.

Сайт:               http://127.0.0.1:8000
Документация API:   http://127.0.0.1:8000/docs
Вход (владелец):    логин muhan   пароль ChangeMe_2026

Чтобы ОСТАНОВИТЬ сервер — просто закройте чёрное окно.


ЕСЛИ НЕТ PYTHON:
  Скачайте с https://www.python.org/downloads/ , при установке
  ПОСТАВЬТЕ ГАЛОЧКУ "Add Python to PATH", потом снова start.bat.


СПОСОБ ДЛЯ ТЕХ, КТО ЛЮБИТ КОМАНДЫ (по желанию):
  python -m venv .venv
  .venv\Scripts\activate
  pip install -r requirements.txt
  python -m app.seed
  python -m uvicorn app.web:app --reload
