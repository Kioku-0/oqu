# Документ 1. Анализ и обзор аналогов

**Проект:** «Оқу» - электронная библиотека с REST API · **Версия:** 2.0 от 21.11.2026

## 1. Проблема

Студентам нашего университета нужны книги на трёх языках, но:

- электронная библиотека вуза (МегаПро, library.korkyt.kz) показывает в основном сканы, а чтобы открыть книгу, нужно найти кнопку «отобрать для заказа», дождаться ссылки и читать в отдельном защищённом просмотрщике; интерфейс непривычный, на телефоне читать неудобно;
- нет места, где можно отметить, что читаешь, продолжить с той же страницы и обсудить книгу с однокурсниками;
- популярные книжные сервисы платные, не знают о студентах нашего вуза и почти не поддерживают казахский язык.

## 2. Пользователи и их цели

| Пользователь | Цель | Главный сценарий |
|---|---|---|
| Студент | Быстро найти и прочитать книгу, в т.ч. новинку бесплатно | Поиск → чтение → продолжение с места остановки |
| Обычный читатель | Читать бесплатные книги, вести свои списки | Полки, закладки, оценки, комментарии |
| Автор / редактор | Публиковать книги, управлять каталогом | Добавить книгу с текстом или PDF, временно сделать её платной |
| Модератор | Поддерживать порядок | Баны с причиной, заявки на разбан, проверка студбилетов, журнал |
| Разработчик / внешняя программа | Получить данные библиотеки | REST API с документацией OpenAPI |

Три основных сценария использования:

1. **«Найти и читать».** Гость ищет «Абай», фильтрует по казахскому языку, открывает книгу и читает; войдя в аккаунт, на следующий день продолжает с того же места.
2. **«Новинка для студента».** Читатель видит платную новинку, загружает фото студбилета; модератор подтверждает - и книга открывается бесплатно.
3. **«Порядок в комментариях».** Пользователь пишет грубый комментарий - слова скрываются; за повторные нарушения модератор банит его на сутки с причиной, тот подаёт заявку на разбан, модератор её рассматривает; всё фиксируется в журнале.

## 3. Обзор аналогов

| Критерий | МегаПро (вуз) | MangaLib | Goodreads | ЛитРес | Storytel | **«Оқу»** |
|---|---|---|---|---|---|---|
| Чтение в браузере | Сканы в защищённом просмотрщике | Да (манга) | Нет (только каталог) | Да | Нет (аудио) | Текст **и** PDF-скан |
| Продолжить с места остановки | Нет | Да | - | Да | Да | Да, автоматически |
| Полки / статусы чтения | Нет | Да: читаю, в планах, брошено… | Да: want / reading / read | Мои книги | Мои книги | Да, 4 статуса |
| Оценки и отзывы | Нет | Да | Да, 1-5 звёзд | Да | Да | Да, 1-5 + комментарии |
| Казахский язык интерфейса | Частично | Нет | Нет | Нет | Нет | **Да (ru/kk/ky/en)** |
| Бесплатно для студентов вуза | Да | Частично | Да | Нет | Нет | Да, новинки - после проверки студбилета |
| Открытый API | Нет | Нет | Закрыт для новых ключей | Нет | Нет | **REST API + OpenAPI** |
| Модерация и журнал действий | - | Модерация | Модерация | - | - | Роли, баны, журнал |

*Сравнение составлено по общедоступным страницам сервисов на ноябрь 2026 г.; цены и условия подписок не рассматривались, так как зависят от региона.*

## 4. Что мы взяли у каждого (и чего избегали)

| Источник | Удачный приём | Как реализовано в «Оқу» |
|---|---|---|
| MangaLib | Полки со статусами «читаю / брошено / прочитано» прямо на странице книги | Сегментированный переключатель статуса под названием книги |
| Goodreads | Оценка звёздами, рейтинг по прочитанному | Звёзды 1-5, сортировка «по оценке», статистика самых читающих |
| ЛитРес / Kindle | Читалка с настройкой шрифта и фона, «продолжить чтение» на главной | Фон «бумага / сепия / ночь», размер шрифта, ширина строки; блок «Продолжить чтение» |
| Storytel | Карусели книг на главной («Новые», «Популярные») | Горизонтальные полосы с прокруткой на главной |
| Kaspi.kz | Крупная строка поиска, нижняя панель на телефоне, понятные короткие подписи | Поиск во всю ширину; на телефоне - нижнее меню из 5 разделов |
| GitHub / YouTube | Горячая клавиша `/` для поиска, «скелетоны» при загрузке | `/` переводит фокус в поиск; серые заглушки вместо пустого экрана |
| Проводник Windows | Режимы просмотра «плитка / список / таблица» | Переключатель вида в каталоге |
| МегаПро (чего избегали) | Многошаговый доступ к книге, неочевидные кнопки | Книга открывается одной кнопкой «Читать»; ссылка на оригинал в МегаПро - отдельной кнопкой |

## 5. Вывод

Ни один аналог не сочетает чтение текста и сканов, казахский интерфейс, бесплатный доступ для студентов вуза и открытый документированный API. «Оқу» закрывает эти пробелы и при этом выполняет обязательные требования варианта 11: FastAPI, JWT, постраничный вывод и журнал действий пользователей.
