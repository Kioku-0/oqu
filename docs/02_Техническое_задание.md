## 1. Введение

### 1.1. Название и цель

«Оқу» (каз. «чтение, учёба») — веб-приложение электронной библиотеки. Цель — дать студентам и преподавателям университета удобный доступ к книгам на русском, казахском и английском языках: найти книгу, прочитать её в браузере, продолжить с места остановки и обсудить с другими читателями. Все функции доступны через REST API, описанный по стандарту OpenAPI, поэтому к той же логике позже подключаются настольный и мобильный клиенты.

### 1.2. Область применения

Библиотека кафедры или университета; учебный проект курса «Разработка кроссплатформенных веб-, мобильных и настольных приложений на Python» (Кызылординский университет имени Коркыт Ата).

### 1.3. Обязательные функции варианта 11

| Требование задания | Где выполнено |
|---|---|
| FastAPI | `app/web.py`, документация `/docs` (Swagger UI) и `/redoc` |
| Аутентификация JWT | `app/security.py`: токены доступа (30 мин) и обновления (7 дней) |
| Постраничный вывод | каталог, комментарии, пользователи, журнал (`page`, `page_size`) |
| Усложнение: журнал действий пользователей с временными метками | таблица `action_log`, раздел «Модерация → Журнал действий», выгрузка CSV |

### 1.4. Термины

| Термин | Пояснение |
|---|---|
| REST API | Набор адресов (`/api/...`), по которым программы обмениваются данными в формате JSON |
| OpenAPI | Стандарт описания API; FastAPI строит по нему страницу `/docs` |
| JWT | JSON Web Token — подписанный «пропуск», который сервер выдаёт после входа |
| Роль | Набор прав пользователя (раздел 2) |
| Полка | Личные списки книг: «Читаю», «Буду читать», «Прочитано», «Брошено» |
| Платная новинка | Книга, доступ к которой временно ограничен; по истечении срока она бесплатна для всех |

## 2. Пользователи и роли

Права распределены по **принципу наименьших привилегий**: каждая роль получает только то, что нужно для её задач. Права проверяются на сервере у каждого запроса (`service.PERMISSIONS`).

| Роль | Кто это | Права |
|---|---|---|
| Гость | Незарегистрированный посетитель | Каталог, поиск, чтение бесплатных книг, статистика |
| Читатель (`user`) | Зарегистрированный пользователь | + полки, закладки, оценки, свои комментарии (писать, изменять, удалять), покупка новинки, заявка на статус студента, удаление своего аккаунта |
| Студент (`student`) | Читатель с подтверждённым студбилетом | + бесплатное чтение платных новинок |
| Автор (`author`) | Автор книг | + добавление книг; изменение и удаление **только своих** книг; приписка «Автор этой книги» |
| Редактор (`editor`) | Отвечает за каталог | + изменение и удаление любых книг, удаление любых комментариев |
| Модератор (`moderator`) | Отвечает за людей | + список пользователей, баны с причиной и сроком, заявки на разбан и на статус студента, журнал действий. **Книгами не управляет** |
| Главный разработчик (`owner`) | Администратор | Все права + назначение ролей и удаление аккаунтов. Не может быть забанен или удалён |

## 5. Ограничения и допущения

- Язык и платформа: Python 3.11+ (проверено на 3.15), FastAPI, SQLite; интерфейс — HTML/CSS/JavaScript без сборщиков.
- SQLite допускает одновременную запись только одним процессом — для учебной нагрузки этого достаточно; при росте нагрузки переход на PostgreSQL (см. Документ 3).
- Оплата книг — учебная имитация: реальные платёжные данные не запрашиваются.
- Книги каталога — произведения в общественном достоянии (короткие начальные фрагменты) и тексты команды проекта; книга библиотеки вуза (МегаПро) подключена ссылкой.
- Сроки: предварительная защита — 24.11.2026, окончательная — 08.12.2026.

## 6. Модель данных (кратко)

Основные объекты: **Пользователь**, **Книга**, **Комментарий**, **Тег**, **Полка**, **Прогресс чтения**, **Закладка**, **Оценка**, **Покупка**, **Заявка студента**, **Бан**, **Заявка на разбан**, **Запись журнала**. Пользователь связан с книгами через полку, прогресс, закладки, оценки, покупки и комментарии («многие ко многим»); книга и тег — «многие ко многим» через `book_tags`. Подробная схема 16 таблиц с ключами и ограничениями — в Документе 3.

## 7. Критерии приёмки

Проект принимается, если на защите:

1. Приложение запускается на чистом компьютере по инструкции (Документ 8) одной командой `start.bat`.
2. `python -m pytest -q` — все тесты пройдены; покрытие логики ≥ 80%.
3. Открывается `/docs`; через Swagger UI можно войти (кнопка **Authorize**) и вызвать защищённый маршрут.
4. Демонстрируются: регистрация с согласием, вход, поиск и постраничный вывод, чтение с продолжением, комментарий с цензурой, бан с причиной и заявкой на разбан, журнал действий с фильтром и выгрузкой CSV.
5. Каждое требование FR/NFR подтверждено тестом или ручной проверкой из Документа 6.
