# Документ 6. План и отчёт о тестировании

**Проект:** «Оқу» · **Версия:** 2.0 · **Дата прогона:** 21.11.2026
**Окружение:** Windows 10 Pro, Python 3.15.0, pytest 9.2, FastAPI 0.165, браузер Chromium (встроенный в Claude Desktop), эмуляция экранов 1280×900 и 375×812.

## 1. План тестирования

| Уровень | Что проверяется | Инструмент | Объём |
|---|---|---|---|
| Модульные тесты | Бизнес-логика `service.py`, `security.py`, `profanity.py`, переводы | pytest, база SQLite в памяти (фикстура `db`) | 130 тестов |
| Покрытие | Доля выполненных строк логики | `run_coverage.py` (без внешних пакетов) | цель ≥ 80% |
| Стиль кода | PEP 8 | ruff (`E, W, F, N`, строка ≤ 79) | весь `app/` и `tests/` |
| Ручные проверки веб-слоя | API через запущенный сервер, интерфейс в браузере, 3 языка, телефон | браузер, DevTools, журнал `oqu.log` | 12 случаев (TC-W) |

Каждый модульный тест получает **новую пустую базу в памяти**, поэтому тесты не влияют друг на друга. Для каждой функции проверяются три вида случаев (как требует методичка): **обычный**, **граничный** и **ошибочный**. Параметризованные тесты (`@pytest.mark.parametrize`) прогоняют один тест на нескольких наборах данных — например, 14 обычных слов, которые цензура не должна трогать.

**Команды:**

```bash
python -m pytest -q
python run_coverage.py
python -m ruff check --select E,W,F,N --line-length 79 app tests
```

## 5. Найденные и исправленные дефекты

| № | Дефект | Как нашли | Исправление |
|---|---|---|---|
| 1 | 500 при параллельных запросах: соединение SQLite закрывалось в другом потоке | ошибка в браузере, трассировка в `oqu.log` | `check_same_thread=False` (у каждого запроса своё соединение) |
| 2 | На телефоне английская шапка расширяла страницу до 546 px | автоматическая проверка ширины | поиск перенесён во вторую строку шапки |
| 3 | Цензура не ловила реальный мат | замечание Мұхана | новый модуль `profanity.py` + 29 тестов |
| 4 | «оскорблять» маскировалась из-за корня «блят» | тест `test_normal_words_untouched` | корень перенесён в правило «только начало слова» |
| 5 | Книга из «Буду читать» не попадала в «Продолжить чтение» | ручная проверка через API | `save_progress` переводит её в «Читаю» + тест |
| 6 | Общая ошибка вместо подсказки у поля (цена > 1 000 000) | замечание Мұхана | разбор ошибок 422 по полям (TC-W04) |
| 7 | 240 000 итераций PBKDF2 — ниже рекомендации OWASP | самопроверка при написании документов | 600 000 итераций; в тестах — уменьшено через переменную окружения |
