# Документ 11. Описание маршрутов (URL, методы, права доступа)

**Проект:** «Оқу» · **Версия:** 2.0 от 21.11.2026 · *Дополнительный документ для веб-приложения*

## 1. Общие правила

- Базовый адрес локально: `http://127.0.0.1:8000`. Все маршруты API начинаются с `/api/`.
- Формат данных — JSON (UTF-8); загрузка файлов — `multipart/form-data`.
- **Авторизация:** после входа (`POST /api/auth/login`) клиент передаёт токен в заголовке
  `Authorization: Bearer <access_token>`. Токен доступа живёт 30 минут, токен обновления — 7 дней (`POST /api/auth/refresh`).
- **Права** проверяются на сервере у каждого запроса по словарю `service.PERMISSIONS`; главный разработчик (`owner`) имеет все права. Скрытые в интерфейсе кнопки — только удобство, а не защита.
- **Постраничный вывод:** параметры `page` (с 1) и `page_size` (1–100); ответ имеет вид
  `{"items": [...], "total": 34, "page": 1, "page_size": 20, "pages": 2}`.
- **Документация OpenAPI:** интерактивная — `/docs` (Swagger UI, кнопка **Authorize** для ввода токена), справочная — `/redoc`, машинная — `/openapi.json`.
- Изменяющие действия выполняются только методами `POST / PUT / PATCH / DELETE`; запросы `GET` данные не меняют (исключение — запись в журнал факта чтения книги).

## 2. Коды ответов

| Код | Когда | Пример тела |
|---|---|---|
| 200 / 201 | Успех / создано | данные или `{"detail": "Книга удалена"}` |
| 400 | Нарушено правило логики | `{"detail": "Укажите причину бана", "code": "validation"}` |
| 401 | Нет токена, токен истёк, неверный пароль | `{"detail": "Требуется авторизация"}` |
| 403 | Недостаточно прав или аккаунт забанен | `{"detail": "Аккаунт заблокирован", "code": "banned", "reason": "...", "until": "..."}` |
| 404 | Объект не найден | `{"detail": "Книга не найдена", "code": "not_found"}` |
| 409 | Конфликт (дубликат, повторная покупка) | `{"detail": "Пользователь с таким логином или почтой уже есть"}` |
| 413 | Файл больше допустимого | `{"detail": "Файл больше 40 МБ"}` |
| 422 | Поле не прошло проверку схемы | список ошибок по полям (FastAPI); интерфейс показывает их у конкретных полей |
| 429 | Слишком много попыток входа | `{"detail": "Слишком много попыток. Повторите позже."}` |
| 500 | Непредвиденная ошибка (подробности — только в журнале сервера) | `{"detail": "Внутренняя ошибка сервера"}` |

## 4. Страницы и служебные адреса

| Адрес | Что отдаёт |
|---|---|
| `GET /` | Одностраничный интерфейс (разделы переключаются по адресу после `#`: `#/catalog`, `#/book/5`, `#/read/5`, `#/admin/log` …) |
| `GET /static/...` | CSS, JavaScript, переводы, иконки, юридические тексты; кэшируются браузером на год (адрес содержит `?v=версия`) |
| `GET /docs`, `GET /redoc`, `GET /openapi.json` | Документация API |

## 5. Параметры каталога `GET /api/books`

| Параметр | Значение | Пример |
|---|---|---|
| `query` | поиск по названию, автору, описанию (≤ 100 симв.) | `query=абай` |
| `author`, `genre`, `tag` | фильтры | `genre=роман` |
| `language` | `ru`, `kk`, `en` | `language=kk` |
| `year`, `year_from`, `year_to` | год или диапазон 0–2100 | `year_from=1800&year_to=1900` |
| `access` | `free` или `paid` | `access=free` |
| `sort` | `title`, `author`, `year`, `created_at`, `rating`, `popular` | `sort=rating` |
| `order` | `asc` или `desc` | `order=desc` |
| `page`, `page_size` | постраничный вывод | `page=2&page_size=20` |

## 6. Пример работы через командную строку

```bash
# 1. Вход — получить токен
curl -X POST http://127.0.0.1:8000/api/auth/login -H "Content-Type: application/json" -d "{\"username\":\"moder01\",\"password\":\"ChangeMe_2026\"}"
# 2. Журнал действий, страница 1, только входы
curl "http://127.0.0.1:8000/api/admin/log?action=login&page=1&page_size=20" -H "Authorization: Bearer <access_token>"
```
