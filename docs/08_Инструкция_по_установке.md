# Документ 8. Инструкция по сборке, установке и запуску

**Проект:** «Оқу» · **Версия:** 2.0 от 21.11.2026

Веб-приложению не нужна «сборка» установочного файла: сервер запускается из исходного кода, а интерфейс открывается в браузере. Ниже — запуск на компьютере (для разработки и защиты). Размещение на сервере в интернете — в Документе 13.

## 1. Системные требования

| Компонент | Требование |
|---|---|
| ОС | Windows 10/11 или Linux (Ubuntu 22.04+); macOS — аналогично Linux |
| Python | 3.11 или новее (проверено на 3.15.0) |
| Место на диске | ~50 МБ (код, зависимости, демо-база) |
| Браузер | актуальный Chrome, Edge, Firefox или Safari |
| Порт | 8000 свободен |

## 2. Быстрый запуск в Windows (одна команда)

1. Скопируйте папку проекта на компьютер (или `git clone`).
2. Дважды щёлкните **`start.bat`**. Скрипт сам:
   - найдёт Python (через реестр Windows, даже если его нет в PATH);
   - установит зависимости из `requirements.txt` (первый раз — около минуты, лог в `instance\logs\setup.log`);
   - создаст демо-базу (если её ещё нет);
   - запустит сервер и откроет сайт в браузере.
3. Сайт: <http://127.0.0.1:8000>, документация API: <http://127.0.0.1:8000/docs>. Остановить — закрыть окно консоли.

## 3. Ручная установка (Windows / Linux)

```bash
git clone <адрес репозитория> oqu
cd oqu
python -m venv .venv
```

Активировать окружение:

```bash
.venv\Scripts\activate
```

(в Linux / macOS: `source .venv/bin/activate`)

```bash
pip install -r requirements.txt
python -m app.seed
python -m uvicorn app.web:app --port 8000
```

`python -m app.seed --reset` удаляет базу и загруженные файлы и создаёт демо-данные заново.

## 5. Настройки (переменные окружения)

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `SECRET_KEY` | Ключ подписи JWT | создаётся случайно в `instance/secret.key` |

## 7. Частые проблемы

| Сообщение | Причина | Решение |
|---|---|---|
| «Python не найден» в `start.bat` | Python не установлен | Установить с python.org, отметить «Add python.exe to PATH» |
| `pip` — «Отказано в доступе» при установке `uvicorn[standard]` | Пакет собирается из исходников на новой версии Python | Используется обычный `uvicorn` (так и указано в `requirements.txt`) |
| `[Errno 10048] … address already in use` | Порт 8000 занят | Закрыть другую копию сервера или запустить с `--port 8001` |
| Сайт открылся, но без стилей | Браузер держит старый кэш | Обновить страницу `Ctrl+F5` |
| «Слишком много попыток входа» | Сработала защита от подбора | Подождать минуту (лимит IP) или 10 секунд (блокировка аккаунта) |

## 8. Запуск на второй платформе (настольное и мобильное приложение)

Логика (`service.py`) не зависит от интерфейса, а все функции доступны через REST API, поэтому для второй платформы нужно написать только новый интерфейс:

- **Настольная версия** — окно на Flet / PySide6, которое вызывает тот же API (или напрямую `service.py` с локальной базой в папке данных пользователя); сборка: `flet build windows`.
- **Мобильная версия** — Flet-клиент того же API; сборка: `flet build apk`. База и файлы — на сервере, на телефоне хранится только токен.
- **Что меняется:** адрес сервера в настройках клиента, хранение токена в защищённом хранилище ОС, перевод интерфейса берётся из `/api/i18n/{lang}`; переключатель языка переносится в настройки (так принято в приложениях). Серверная часть не меняется.
