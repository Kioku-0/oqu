Python — язык программирования, который ценят за простоту и читаемость. Код на Python похож на обычный английский текст: в нём нет лишних скобок, а блоки выделяются отступами. Поэтому Python часто становится первым языком для студентов.

Программа — это последовательность инструкций. Самая простая программа выводит текст на экран: print("Сәлем, әлем!"). Функция print получает значение и показывает его пользователю.

Переменная — это имя, за которым хранится значение. Запись books = 12 создаёт переменную books со значением 12. Python сам понимает тип данных: целое число, строка, список или словарь.

Списки хранят несколько значений по порядку: genres = ["роман", "поэзия", "учебник"]. Словари хранят пары «ключ — значение»: book = {"title": "Қара сөздер", "author": "Абай"}. Именно словари мы используем, когда отдаём данные через REST API в формате JSON.

Функция — это именованный кусок кода, который можно вызывать много раз. В нашем проекте вся бизнес-логика собрана в функциях модуля service.py: register_user, add_book, search_books и другие. Они не знают ничего о сайте, поэтому их легко тестировать.

Тест — это маленькая программа, которая проверяет другую программу. Например, тест проверяет, что пароль короче восьми символов не принимается. Библиотека pytest находит все функции, имена которых начинаются с test_, и запускает их одной командой.

REST API — это способ общения программ через интернет. Клиент отправляет запрос, например GET /api/books, а сервер отвечает данными в формате JSON. Фреймворк FastAPI строит такой API на Python и сам создаёт его документацию по стандарту OpenAPI.

Безопасность начинается с паролей. Хранить пароль в открытом виде нельзя: если базу украдут, злоумышленник получит все пароли. Поэтому мы храним только хэш — результат одностороннего преобразования, из которого пароль восстановить невозможно.

После входа сервер выдаёт JWT-токен — подписанный «пропуск» с ограниченным сроком действия. Браузер прикладывает его к каждому запросу, а сервер проверяет подпись и понимает, кто пришёл и какие у него права.

Базы данных хранят информацию надёжно и упорядоченно. SQLite — база данных в одном файле: её не нужно отдельно устанавливать, и для учебного проекта этого достаточно. Все запросы к ней мы пишем с параметрами-заполнителями «?», чтобы исключить SQL-инъекции.

Последний совет: пишите код так, чтобы его было приятно читать. Стандарт PEP 8 описывает, как называть переменные, где ставить пробелы и какой длины делать строки. Хороший код — это код, который понятен не только компьютеру, но и человеку.
